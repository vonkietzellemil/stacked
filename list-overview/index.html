What's new?

v: 1.0.0

New user interface (UI)

•

The UI has been completely redesigned for a better user experience.

Theme colors

•

Personalize the app with our new selection of theme color presets.

Choose theme color.

Searchbar

•

A searchbar has been added, allowing users to quickly find and manage their lists or entries.

v: 1.1.0

Onboarding guide for new users.

•

New users now get introduced to the app’s key features upon opening it the first time.

Update news page

•

Update changes are listed here on the update news page and can be reviewed any time in the settings.

•

Users get notified with a pop-up, leading to this page, whenever a new version is available.
(This can be disabled in the settings)

v: 1.2.0

Select entries or lists by long pressing them and perform various actions such as:

•

duplicating them,

•

deleting multiple at once

•

or moving entries between lists.

Small adjustments:

•

Selecting entries and lists feels smoother and more intuitive.

v: 1.2.1

New options for lists and entries when you select them:

•

Share your lists/entries with anyone

•

Export lists and entries

Sorting

•

The sort button has been updated to free up space for upcoming features
and support more modes.

•

Accordingly, we've added new sort modes:
For lists: oldest, highest counter
For entries: newest, oldest

Smart Search

•

The searchbar now also searches through the list's or entry's content to find relevant results.

•

Search results are intelligently ranked based on relevance.

v: 1.4.0

New options for selected items:

•

Lists can be archived by selecting them and clicking the archive option.

•

Archived lists can be viewed using the archive icon in the actions bar above the lists.

•

Unarchive them by selecting the lists and clicking the unarchive option.

•

Entries can be checked off by selecting them and clicking the checkbox on the right of the entry.

Filter (Safari only)

•

Filter lists or entries to find what you're looking for faster.

v: 1.4.1

We...

•

...fixed some bugs.

•

...improved the onboarding experience.

v: 1.4.2

More bug fixes

•

...fixed an issue where entry order was not correctly preserved when exporting and importing lists.

•

...fixed a bug where exporting multiple lists would result in only one list keeping its entries after import.

•

...fixed a bug where marking an entry as favorite or checked would overwrite the other status. Entries can now be both checked and favorited at the same time.

v: 1.5.0

Trash Bin

•

Deleted items are now moved to a trash bin instead and remain there for 15 days before being permanently removed.

•

You can now restore items from the trash bin at any time within the 15-day period.

•

The trash bin can be accessed from the action bar above the lists.

v: 1.5.1

Trash can

•

Deleted items can now be permanantly deleted from the trash can by selecting them.

•

You can also restore multiple items at once that way.

Refresh

•

The refresh icon has been removed from the action bar.

•

To refresh you have to pull the page down.
